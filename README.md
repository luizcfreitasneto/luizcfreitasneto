## 📂 Projetos em destaque

### 📊 1. PNCP 2025 — Pipeline de Dados e Business Intelligence

Projeto Final do Módulo 2 do SC Tec, utilizando dados de contratações públicas do Portal Nacional de Contratações Públicas (PNCP).

**Atividades desenvolvidas:**
- Inspeção e auditoria de arquivos CSV.
- Análise de aproximadamente 25 mil registros distribuídos entre compras, itens e resultados.
- Tratamento de dados monetários e formatos de datas.
- Verificação de integridade e relacionamentos.
- Desenvolvimento de rotinas de limpeza e transformação com Python e Pandas.
- Modelagem dimensional no PostgreSQL.
- Construção de dashboards no Power BI.

**Tecnologias:** Python, Pandas, PostgreSQL, SQL, Power BI e Git.

🔗 [Acessar repositório](https://github.com/luizcfreitasneto/projeto-final-modulo-2-sc-tec)

### 🥇 2. Engenharia de Dados — Arquitetura Medallion (Raw, Silver e Gold)

Projeto acadêmico desenvolvido no programa SC Tec, utilizando uma arquitetura de dados organizada em três camadas.

**Arquitetura:**
- **Raw:** ingestão e preservação dos dados originais.
- **Silver:** limpeza, padronização, transformação e validação dos dados.
- **Gold:** organização de dados tratados para consumo analítico e geração de indicadores.

**Competências aplicadas:** arquitetura de dados, processamento de dados, ETL/ELT, qualidade de dados e organização de pipelines.

🔗 [Acessar repositório](https://github.com/luizcfreitasneto/projeto-final-modulo-01-sc-tec-etl-medallion)

### 🐾 3. Pata Amiga — Data Warehouse com PostgreSQL

Projeto acadêmico baseado em uma rede fictícia de petshops de Santa Catarina, voltado à construção de um ambiente analítico.

**Atividades desenvolvidas:**
- Criação de estruturas de staging.
- Modelagem dimensional com tabelas fato e dimensões.
- Desenvolvimento de scripts SQL no PostgreSQL 16.
- Padronização e tratamento de dados.
- Construção de relacionamentos entre entidades.
- Desenvolvimento de consultas para indicadores comerciais e operacionais.

**Indicadores abordados:** ticket médio, canais de pedidos, desempenho operacional e gargalos nas etapas de atendimento.

**Tecnologias:** PostgreSQL 16, SQL, pgAdmin e Data Warehouse.

🔗 [Acessar repositório](https://github.com/luizcfreitasneto/dw-pata-amiga)

### 🛒 4. Análise de Dados de Varejo — Python e Pandas

Projeto de análise exploratória de uma base de aproximadamente **830 mil registros**.

**Atividades desenvolvidas:**

- Tratamento e análise de informações comerciais.
- Identificação de categorias e produtos com maior frequência.
- Criação de visualizações e documentação dos resultados.

**Tecnologias:** Python, Pandas, Matplotlib e Seaborn.
